## Structure of the repo.

Each lab is pushed to a **separate Git branch** to keep the main branch clean and organized.

| Branch Name | Description |
| ----------- | ----------- |
| `lab-1`     | Portfolio   |
| `lab-2`     | userList    |
| `lab-3`     | MoviesAPI   |

> The `main` branch contains no active lab — only the structure or documentation.
